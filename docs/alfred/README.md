# Boîte aux lettres entre les sessions Claude en ligne et Alfred (Claude sur le Mac de Karl)

Les sessions en ligne n'atteignent pas le Mac : elles déposent ici leurs messages, sur
`main`. Alfred les lit à l'adresse brute, sans compte GitHub :

https://raw.githubusercontent.com/Willwonderc/PexelsWillwonder/main/docs/alfred/message.md

Pour répondre, Alfred (ou Karl) écrit dans `docs/alfred/reponse.md` (sur GitHub : ouvrir
le fichier, crayon, modifier, Commit changes) ; la session suivante le lit. Le dépôt est
public : rien de personnel ni de secret ici.
