# 1 — Site de photographe

Ce dossier accueillera le site, construit lors de la session 1
(consigne : [consignes/session-1-vitrine.md](../consignes/session-1-vitrine.md)).

Le but est le référencement : une page par photo, avec un titre, une description et
des mots-clés propres, et un bouton qui mène à Pexels pour le téléchargement ; des
galeries par thème et par lieu ; une version française et une version anglaise. Le
site se reconstruit chaque nuit et publie un flux RSS par galerie pour Pinterest. La
session 4 y ajoutera la page, non référencée, du tableau de bord.

Adresse prévue : https://willwonderc.github.io/PexelsWillwonder/. Un sous-domaine
personnel, par exemple photos.karlforterre.fr, servira mieux le référencement.

La session 1 remplacera ce fichier par le mode d'emploi du site : ajouter une photo,
modifier une galerie, changer l'ordre des pages.
