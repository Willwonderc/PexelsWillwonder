# 1 — Vitrine photo reliée à Pexels

Ce dossier accueillera le code du site vitrine, construit lors de la session 1
(consigne : [consignes/session-1-vitrine.md](../consignes/session-1-vitrine.md)).

En résumé : une page d'accueil et une page par collection Pexels, en français et en
anglais ; chaque photo renvoie vers sa page Pexels ; un flux RSS des dernières photos ;
une reconstruction automatique chaque nuit, publiée sur GitHub Pages. La session 4 y
ajoutera la page, non référencée, du tableau de bord.

Adresse prévue : https://willwonderc.github.io/PexelsWillwonder/ (un sous-domaine
personnel, par exemple photos.karlforterre.fr, reste possible).

La session 1 remplacera ce fichier par le mode d'emploi du site : ajouter une photo,
changer l'ordre des pages.
